# LYWSD02 Clock Sync

Time synchronization tool for Xiaomi Mijia BT4.0 Wireless Smart Electric Digital Clock.

## Description

This is a clock sync application that keeps the Xiaomi Mijia BT4.0 Wireless Smart Electric Digital Clock synchronized with the system time. It provides a web-based interface to update and verify the clock time.

## Features

- **Time Sync**: Updates the clock with the current system time
- **Visual Indicator**: Displays the current time on the clock face
- **Progress Tracking**: Shows synchronization progress
- **Experimental Features**: Requires enabling Experimental Web Platform features in the browser

## Files

- `LYWSD02ClockSync.html` - Main HTML interface
- `LYWSD02ClockSync.css` - Stylesheet
- `LYWSD02ClockSync.js` - Client-side logic
- `assets/` - Clock icon and assets

## Usage

1. Open the index page in a browser
2. Click "Update time" to sync with the system clock
3. View the current time display
4. Ensure Experimental Web Platform features are enabled for full functionality
