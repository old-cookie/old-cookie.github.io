# WaterMark

照片水印工具 - Photo Watermark Tool

## Description

A photo watermark tool that allows users to upload images, add watermarks, preview them, and download the watermarked images. Built with Blades CSS framework.

## Features

- Upload multiple images
- Preview watermarked images
- Download all images as a batch

## Files

- `WaterMark.html` - Main HTML interface
- `WaterMark.css` - Custom styles
- `WaterMark.js` - Client-side logic
- `State.js` - Application state
- `File.js` - File handling
- `UI.js` - UI utilities
