# Avatar Preview

個人頭像裁切器 - Avatar Cropper & Preview Tool

## Description

This is an avatar preview and cropping tool that allows users to upload images and crop/preview them. The tool is built with Blades CSS framework and includes:

- **Image Upload**: Upload photos for preview
- **Crop Functionality**: Crop images to create profile avatars
- **Download**: Export cropped images as PNG

## Features

- Upload image files (JPEG, PNG, etc.)
- Crop the uploaded image to create a profile avatar
- Download the cropped image as a PNG file
- Responsive design with Blades CSS framework

## Files

- `AvatarPreview.html` - Main HTML interface
- `AvatarPreview.css` - Custom styles
- `AvatarPreview.js` - Client-side logic
- `AvatarPreview.css` - Stylesheet

## Usage

1. Open the index page in a browser
2. Click "Upload" to select an image
3. Use the crop tool to select and crop the image
4. Download the cropped PNG
